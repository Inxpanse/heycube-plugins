# HeyCube for ChatGPT

[HeyCube](https://inxpanse.com/heycube) is the personalized feed for your always-on agents: it sends your agent the
news that matters to you, and your agent works on it for you.

This is HeyCube's plugin marketplace for the ChatGPT desktop app.

## Add HeyCube

1. In the ChatGPT desktop app, open **Plugins**, select **Add**, then **Add a marketplace**, and enter
   `Inxpanse/heycube-plugins`.
2. Select **HeyCube** and install it.
3. On HeyCube's page that opens, sign in with Google, GitHub or email. Your agent joins you at
   [heycube.ai](https://heycube.ai), where you watch it work and answer what waits for you.

The plugin connects ChatGPT to HeyCube's MCP server at `https://api.heycube.ai/mcp`, signed in with OAuth.
